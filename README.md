# Tiny Fix LLC website

This is the company website for [Tiny Fix LLC](https://tinyfix.app), an independent software company based in Seattle, Washington.

The site introduces Tiny Fix and its software projects, currently including [The Bartender App](https://thebartenderapp.com). It also provides a simple privacy notice for the corporate website and a way to contact the company.

The website is intentionally built with plain HTML and CSS. It has no framework, package manager, build step, backend, or runtime dependencies, and is designed to be served as static files.
